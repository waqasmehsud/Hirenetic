# Candidate Cross-Match Panel (Free Tier)

## Overview

Compare a candidate's CV with publicly available profiles to help HR verify skills, projects, and professional information.

No paid APIs required.

---

# Dashboard

* Total Candidates Checked
* Verified Candidates
* Needs Review
* Average Match Score

---

# Candidate Search

Search by:

* Name
* Email

---

# Candidate Information

Display:

* Name
* Email
* Resume
* Applied Position

---

# Public Profile Links

Store optional links:

* GitHub
* LinkedIn
* Portfolio Website

---

# GitHub Verification

If a GitHub profile is provided:

Display:

* Username
* Public Repositories
* Main Languages
* Recent Activity
* Profile Availability

Simple checks:

* Technologies found in repositories
* Number of repositories
* Portfolio projects found on GitHub

---

# LinkedIn Verification

Display only information already available from the candidate or publicly accessible:

* Profile URL
* Current Position
* Experience
* Education

Compare with the CV:

* Job Titles
* Company Names
* Education
* Skills

---

# Portfolio Verification

If a portfolio URL exists:

Check:

* Website is reachable
* Project section exists
* Contact information available
* GitHub links available

---

# Match Summary

Simple percentage scores:

* Skills Match
* Experience Match
* Projects Match
* Overall Match

Example:

* Skills: 82%
* Experience: 90%
* Projects: 75%

Overall Match: 82%

---

# Warnings

Show badges such as:

* Missing GitHub
* Missing Portfolio
* LinkedIn Not Added
* Skills Not Found
* Manual Review Recommended

---

# HR Notes

* Internal Notes
* Verification Status

Status:

* Verified

* Rejected
